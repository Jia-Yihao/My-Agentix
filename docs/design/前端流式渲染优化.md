## 1. 前后端帧流架构（W6 视角）

```text

        │
        ▼

        │   progress→stepper、tool_running→toolActivity、answer_chunk 累加不清 progress、
        │   finished→收口（progress=null、工具折叠 history、timing 落位）
        ▼

        │
        ▼
useConversationChat.displayMessages（投影缓存：结构相等 ⇒ 复用引用，仅流式消息原地更新）
        │
        ▼
ChatPanel（smartScroll 贴底跟随）→ ChatMessageList（渲染核）

        ├─ 助手 v-html = memoRenderMarkdown(sanitize 后) + 流式光标
        ├─ timing-chip（耗时/首字）、msg-actions（复制/重新生成）、trace 受控展开
        └─ 用户消息恒纯文本
```

## 2. 三大性能策略

### A1 批渲染缓冲（`composables/useStreamBuffer.ts`）

- **问题**：每 token 同步 mutate 深层响应式状态 ⇒ 高峰 ~50–80 次/s 全量重渲染。
- **方案**：可缓冲帧（`progress`/`thinking_chunk`/`tool_running`/非空 `answer_chunk`）入队，**50ms 窗口**到期一次性按序 flush（`isBufferablePayload` 判定）；Vue 同一同步块内多次变更合并为一次渲染。
- **契约**：① 顺序恒等（flush 按原序同步 apply，与逐帧结果一致，测试钉死）；② 终帧 `pushNow` 先落缓冲再应用（先缓冲后终态）；③ abort 走 `try/finally flush` 兜底，部分回答不丢；④ `onFlush` 一窗最多一次（吸底等渲染后处理不重复跑）。
- **控制帧不进缓冲**（finished/error 即时直通），终态语义不因缓冲延迟。

### A2 智能吸底（`utils/scrollBehavior.ts` + `ChatPanel`）

- 纯函数 `bottomGap` / `shouldStickToBottom`（**阈值 80px**，负值归 0，空内容视为贴底）。
- `ChatPanel`：@scroll rAF 节流记录贴底态；流式增量只在**贴底时**自动下滚（`useConversationChat` 新增 `onChunkScroll` 选项），用户上翻**不打扰**；离开底部浮现「↓ 回到底部」胶囊（`content-area` 内绝对定位）。切会话/发送仍走 `onScroll` 强制回底。

### A3 Markdown 流式渲染（`utils/markdown.ts`）

- 链路：`marked.parse`（gfm + breaks）→ `DOMPurify.sanitize` → `v-html`。**绝不裸 v-html**：异常降级 `escapeHtml` 纯文本。
- `memoRenderMarkdown` Map 缓存（同输入不重复 parse，>200 条整体清空防泄漏）；解析只发生在批 flush 后的组件渲染节拍，而非每 token。
- 用户消息保持纯文本（`{{ }}` 插值），不做 markdown。
- 流式光标：sanitize **之后**拼受信常量 `<span class="stream-caret">`（不进消毒器，不破坏消毒边界）。
- 测试环境注意：DOMPurify 依赖真实 DOM 语义，消毒断言文件级 `// @vitest-environment jsdom`（happy-dom 节点突变与消毒器不兼容）。

## 4. 优化前后量化对照

| 维度 | 优化前 | 优化后 | 口径 |
|---|---|---|---|
| 流式渲染次数 | 每 token 一次（高峰 ~50–80 次/s） | 每 50ms 窗一次（≤ ~20 次/s） | 批缓冲窗口（A1），帧序恒等由测试断言 |
| progress 显示时长 | 首个 answer_chunk 即清空（stepper 闪现即逝） | 保持到 finished（生成期 compact 并存） | B4 回归测试「进度持续显示」 |
| 工具文案位置 | 写入 thinking（污染思考区） | 独立工具卡 + 终帧折叠历史 | B5 + `chatStreamHandlers` 13 例 |

| 反馈通道 | `window.alert` 阻断（modal 3 处） | 非阻断 toast（3s 自动消失） | B10 `useToast` 6 例 |
| 助手消息 | 纯文本 | sanitize 后 markdown + 光标 | A3 XSS 样本 4 例（jsdom） |
