# 数据集与数据准备（测试数据集领域）

> 本文承接 README 的数据准备章节。首页见 [README](../../README.md)。

本项目的测试数据集知识来自三类数据文件，分别对应图谱检索（graphrag）、社区摘要（LightRAG）与向量检索（kb）三条路径。数据已于 2026-07-27 由免费结构化开源数据集 **laubeing-droid/legal-cn-core-codices**（GitHub）自动填充：含《示例数据集 A》《示例数据集 B》《用工文档法》《宪法》四部测试数据全文与 67 个示例说明节点（含全文），数据条目正文均为真实文本，无 `【占位】` 残留。可复用 `scripts/data/build_legal_dataset.py` 从源重新生成。

| 文件 | 路径 | 用途 | 当前状态 |
|------|------|------|---------|
| 测试数据本体种子 | `data/legal/legal_seed.json` | 结构化 Neo4j 本体（数据集 / 章节 / 数据条目 / 数据分类 / 示例说明 / 机构 + 关系），由 `scripts/legal_kg_to_csv.py` 转 CSV 后灌库 | ✅ 已填充：4 部数据集 / 1953 数据条目 / 章节(示例数据集 A109·示例数据集 B42·用工文档法1·宪法11) / 67 示例说明 / 7 机构 |

## 已建模覆盖范围（2026-07-27 实际填充）

- **数据集**：《示例数据集 A》（1260 条 / 109 章节）、《示例数据集 B》（452 条 / 42 章节）、《用工文档法》（98 条 / 1 章节）、《宪法》（143 条 / 11 章节）——共 1953 数据条目（用工文档法仅 1 章节系源数据集未嵌章节标记所致，非缺陷）
- **数据分类**：示例文档异常、用工文档解除、盗窃、正当防卫、离婚财产分割（类别二 / 类别一分类）
- **示例说明**：《关于适用〈中华人民共和国示例数据集 A〉示例文档编通则若干问题的解释》（最高处理机构，法释〔2023〕13号）
- **机构**：全国人民代表大会、全国人民代表大会常务委员会、最高处理机构、最高监督机构、国务院、市场监管总局
- **关系**：`属于`（数据条目 → 章节 → 数据集）、`引用`（数据条目互引）、`对应数据分类`、`有示例说明`、`数据来源`、`上级数据集`

## 填充真实数据

1. **数据集 / 数据条目 / 章节 / 机构**：从 **国家测试数据集数据库**（`flk.npc.gov.cn`，全国人大官方、免费）获取数据集名、条号、条文原文、数据编号、生效日期、数据来源。
2. **示例说明**：从 **最高处理机构官网**（`court.gov.cn`）获取 name / 发布来源 / 日期 / 编号。
3. **数据分类分类**：参照《类别二案件数据分类规定（2020）》。
4. 将官方文本替换 `legal_seed.json` / `legal_lightrag_corpus.json` / `legal_corpus.txt` 中所有 `【占位】` 字段；`legal_lightrag_corpus.json` 使用 `title`（条目标题）/ `content`（条文全文）字段名。
5. 重新灌库：
   - **图谱**：`python scripts/legal_kg_to_csv.py` 生成 CSV → Dockerfile `neo4j_seeded` 阶段导入；
   - **向量库**：`kb_ingest` 重新导入 `legal_corpus.txt`（项目已生成 `.kb_milvus_ingested` 标记，表示 kb 向量库已初始化）；
   - **LightRAG**：Dockerfile LightRAG build 阶段读取 `legal_lightrag_corpus.json`。

> 提示：数据条目互引（`引用`）关系通常由 LLM 从条文正文中半自动抽取（识别"参见第X条"等表述），建议填完真实条文后统一补充。
