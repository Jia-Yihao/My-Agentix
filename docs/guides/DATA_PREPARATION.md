# 数据集与数据准备（法律法规领域）

> 本文承接 README 的数据准备章节。首页见 [README](../../README.md)。

本项目的法律法规知识来自三类数据文件，分别对应图谱检索（graphrag）、社区摘要（LightRAG）与向量检索（kb）三条路径。数据已于 2026-07-27 由免费结构化开源数据集 **laubeing-droid/legal-cn-core-codices**（GitHub）自动填充：含《民法典》《刑法》《劳动合同法》《宪法》四部法律全文与 67 个司法解释节点（含全文），法条正文均为真实文本，无 `【占位】` 残留。可复用 `scripts/data/build_legal_dataset.py` 从源重新生成。

| 文件 | 路径 | 用途 | 当前状态 |
|------|------|------|---------|
| 法律本体种子 | `data/legal/legal_seed.json` | 结构化 Neo4j 本体（法规 / 章节 / 法条 / 案由 / 司法解释 / 机关 + 关系），由 `scripts/legal_kg_to_csv.py` 转 CSV 后灌库 | ✅ 已填充：4 部法规 / 1953 法条 / 章节(民法典109·刑法42·劳动合同法1·宪法11) / 67 司法解释 / 7 机关 |
| LightRAG 语料 | `data/legal/legal_lightrag_corpus.json` | 法条 / 司法解释全文，供 `scripts/init_lightrag.py --source json` 建社区摘要索引 | ✅ 已填充：4865 条（1953 法条 + 2912 司法解释条文） |
| 知识库语料 | `data/kb/legal_corpus.txt` | 「一条法条一段」文本，由 `kb_ingest` 导入 Milvus（R3.4 统一向量口径） | ✅ 已填充：4865 块（与 LightRAG 同源） |

## 已建模覆盖范围（2026-07-27 实际填充）

- **法规**：《民法典》（1260 条 / 109 章节）、《刑法》（452 条 / 42 章节）、《劳动合同法》（98 条 / 1 章节）、《宪法》（143 条 / 11 章节）——共 1953 法条（劳动合同法仅 1 章节系源数据集未嵌章节标记所致，非缺陷）
- **案由**：合同违约、劳动合同解除、盗窃、正当防卫、离婚财产分割（民事 / 刑事分类）
- **司法解释**：《关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（最高人民法院，法释〔2023〕13号）
- **机关**：全国人民代表大会、全国人民代表大会常务委员会、最高人民法院、最高人民检察院、国务院、市场监管总局
- **关系**：`属于`（法条 → 章节 → 法规）、`引用`（法条互引）、`对应案由`、`有司法解释`、`制定机关`、`上位法`

## 填充真实数据

1. **法规 / 法条 / 章节 / 机关**：从 **国家法律法规数据库**（`flk.npc.gov.cn`，全国人大官方、免费）获取法规名、条号、条文原文、发文字号、生效日期、制定机关。
2. **司法解释**：从 **最高人民法院官网**（`court.gov.cn`）获取 name / 发布机关 / 日期 / 文号。
3. **案由分类**：参照《民事案件案由规定（2020）》。
4. 将官方文本替换 `legal_seed.json` / `legal_lightrag_corpus.json` / `legal_corpus.txt` 中所有 `【占位】` 字段；`legal_lightrag_corpus.json` 使用 `title`（条款标题）/ `content`（条文全文）字段名。
5. 重新灌库：
   - **图谱**：`python scripts/legal_kg_to_csv.py` 生成 CSV → Dockerfile `neo4j_seeded` 阶段导入；
   - **向量库**：`kb_ingest` 重新导入 `legal_corpus.txt`（项目已生成 `.kb_milvus_ingested` 标记，表示 kb 向量库已初始化）；
   - **LightRAG**：Dockerfile LightRAG build 阶段读取 `legal_lightrag_corpus.json`。

> 提示：法条互引（`引用`）关系通常由 LLM 从条文正文中半自动抽取（识别"参见第X条"等表述），建议填完真实条文后统一补充。
